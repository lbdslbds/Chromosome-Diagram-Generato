# Chromosome-Diagram-Generator

### 基因染色体绘图生成器

这是一个基于 Python 的桌面应用程序，利用 **Matplotlib** 的绘图能力和 **Tkinter** 的图形界面，旨在帮助用户快速生成、自定义并保存生物学染色体对（同源染色体）及其等位基因的示意图。

非常适合生物学教学、课件制作、遗传学笔记或科研绘图。

## ✨ 主要功能

  * **自定义等位基因**：支持分别设置左右染色体顶部、中部和底部的基因符号（如 A, a, B, b）。
  * **智能排版**：根据输入的基因字符长度，自动调整字体大小，确保显示美观。
  * **个性化配色**：
      * 自定义染色体线条颜色。
      * 自定义背景颜色。
  * **性染色体标记**：支持底部添加 "XY"、"XX" 标记或选择不标记。
  * **高清导出**：支持将图像保存为高分辨率的 PNG 图片（300 DPI）。
  * **图形用户界面 (GUI)**：操作简单，无需编写代码即可生成图像。

## 🛠️ 安装说明

在运行此程序之前，请确保您的电脑上已安装 Python 环境。

1.  **克隆或下载本仓库**

    ```bash
    git clone https://github.com/lbdslbds/Chromosome-Diagram-Generato.git
    cd Chromosome-Diagram-Generato
    ```

2.  **安装依赖**
    本项依赖于 `matplotlib` 等库。仓库中已包含 `requirements.txt` 文件，可以通过以下命令一键安装：

    ```bash
    pip install -r requirements.txt
    ```


## 🚀 使用方法

1.  运行主程序文件：

    ```bash
    python Chromosome-Diagram-Generator.py
    ```

2.  **在弹出的窗口中操作**：

      * 在 **“基因定义”** 区域输入左右染色体各位置的基因代号（支持留空）。
      * 在 **“选项”** 区域点击按钮选择您喜欢的背景色和线条色。
      * 选择底部的性染色体标记类型。
      * 点击 **“生成图像”** 或 **“选择保存位置”**。

3.  生成的图片将保存到您指定的路径。
